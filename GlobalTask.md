Задача: В данный момент мое приложение представляет собой FastAPI приложение, состоящее из нескольких
микросервисов. Требуется спроектировать монолит с модульной архитектурой.


Сервис: Map Service

Overview:
Сервис предназначен для работы с полигонами. Пользователь может выделять определенную область на 
карте в виде полигона, для которой в дальнешйем будут запрашиваться снимки за указанный период из 
открытого хранилища и передаваться на анализ модели для детектирования кораблей.

Use cases:
- Создать полигон
- Получить информацию о полигоне
- Получить список полигонов пользователя
- Обновить полигон
- Удалить полигон

Сущности:
- Polygon

Инварианты:
- Полигон имеет не менее 3 уникальных координат
- Полигон замкнут
- Площадь полигона > 0
- Отсутствие самопересечений ребер
- Геометрия в формате GeoJson
- Полигон принадлежит только одному пользователю
- У одного пользователя не может быть двух полигонов с одинаковым именем
- Количество полигонов пользователя не превышает 100
- Площадь полигона должна быть в допустимых пределах [min_area, max_area] кв. км, min_area=1, max_area=2000
- Координаты точек полигона должны быть в формате EPSG:4326
- Координаты точек полигона должны находиться в допустимых географических границах согласно формате EPSG:4326
- Пользователь может просматривать/обновлять/удалять только свои полигоны
- При удалении полигона все связанные с ним данные также должны быть удалены (снимки, результаты детектирования)


Сервис: Image Service

Overview:
Сервис предназначен для работы со снимками из открытого хранилища Sentinel Hub. Пользователь выбирает полигон, указывает
период (начальную и конечную даты), за который хочет получить снимки для данной области. Предпросматривает их и если они
его устраивают - сохраняет. Далее эти снимки будут отправлены на анализ (обнаружение кораблей).

Use cases:
- Запрос снимков из Sentinel Hub для указанного полигона
- Предпросмотр снимков для указанного полигона (наложить на карту для просмотра, без сохранения самих снимков)
- Сохранение снимков после предпросмотра для указанного полигона
- Получить снимки после сохранения (наложить на карту для просмотра) для указанного полигона
- Удалить снимки для указанного полигона

Сущности:
- Image

Инварианты:
- Период не может быть пустым
- Дата начала не может быть больше текущей даты
- Дата начала должна быть раньше или равна дате окончания
- Снимок не может существовать без привязки к полигону
- При удалении снимков для указанного полигона каскадно удаляются результаты детектированиял
- Новые снимки запрашиваются только если изменилась геометрия полигона или период съемки
- Снимки сделаны спутником Sentinel-2 L2A
- Облачность на снимке не должна превышать 20%
- Разрешение снимка 10 метров на пиксель
- Снимки запрашиваются размером 640 на 640 пикселей так, чтобы покрыть весь полигон
- Используются только RGB-каналы
- Формат снимка TIFF
- Пользователь может видеть/удалять снимки только для своих полигонов


Сервис: User Service

Overview:
Сервис предназначен для регистрации и авторизации пользователей. Используется фреймворк FastAPI Users
для реализации. Существует две группы: Пользователь и Администратор. 

Use cases:
- Регистрация с помощью почты
- Подвтерждение аккаунта через отправку письма на почту
- Авторизация по почте и паролю
- Сброс пароля
- Выход из аккаунта
- Получить информацию о текущем пользователе

Сущности:
- User
- Group

Инварианты:
- Время жизни access_token составляет 30 минут
- Пользователь может принадлежать только к одной группе


Сервис: Analysis Service

Overview:
Сервис предназначен для анализа спутниковых снимков. Выполняется детектирование обектов (кораблей)
с помощью модели YOLO для выбранного полигона. Результаты детектирования (bbox) наносятся вместе 
со снимками на карту

Use cases:
- Анализ спутниковых снимков для указанного полиога
- Получить информацию о результе детекции для указанного полигона

Сущности:
- DetectionResult

Инварианты:
- Анализ может быть выполнен только для полигона, у которого есть сохраненные снимки
- Результаты детекции должны быть трансформированы в географические координаты для отображения на карте

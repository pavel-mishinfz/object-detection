Сервис: Image Service

Overview:
Сервис предназначен для работы со снимками из открытого хранилища Sentinel Hub. Пользователь выбирает полигон, указывает
период (начальную и конечную даты), за который хочет получить снимки для данной области. Предпросматривает их и если они
его устраивают - сохраняет. Далее эти снимки будут отправлены на анализ (обнаружение кораблей).

Use cases:
- Запрос снимков из Sentinel Hub для указанного полигона
- Предпросмотр снимков для указанного полигона (наложить на карту для просмотра, без сохранения самих снимков)
- Сохранение снимков после предпросмотра для указанного полигона
- Получить снимки после сохранения (наложить на карту для просмотра) для указанного полигона
- Удалить снимки для указанного полигона

Сущности:
- Image

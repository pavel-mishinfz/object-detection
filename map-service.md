Сервис: Map Service

Overview:
Сервис предназначен для работы с полигонами. Пользователь может выделять определенную область на карте в виде полигона,
для которой в дальнешйем будут запрашиваться снимки за указанный период из открытого хранилища и передаваться на анализ 
модели для детектирования кораблей.

Use cases:
- Создать полигон
- Получить информацию о полигоне
- Получить список полигонов пользователя
- Обновить полигон
- Удалить полигон

Сущности:
- Polygon

Инварианты:
- Полигон имеет не менее 3 уникальных координат
- Полигон замкнут
- Площадь полигона > 0
- Отсутствие самопересечений ребер
- Полигон принадлежит только одному пользователю
- У одного пользователя не может быть двух полигонов с одинаковым именем
- Количество полигонов пользователя не превышает 100
- Площадь полигона должна быть в допустимых пределах [min_area, max_area] кв. м, min_area=1, max_area=2000
- Координаты точек полигона должны быть в формате EPSG:4326
- Координаты точек полигона должны находиться в допустимых географических границах согласно формате EPSG:4326
- Пользователь может просматривать/обновлять/удалять только свои полигоны
- При удалении полигона все связанные с ним данные также должны быть удалены (снимки, результаты детектирования)
